# 📏 Python Unit Converter

A simple and modern **Unit Converter** desktop application built with **Python and Tkinter**.

The application allows users to quickly convert different units of **length, weight, temperature, and volume** through an easy-to-use graphical interface.

---

## ✨ Features

- 📏 Length conversion
  - Millimeter
  - Centimeter
  - Meter
  - Kilometer

- ⚖️ Weight conversion
  - Milligram
  - Gram
  - Kilogram

- 🌡️ Temperature conversion
  - Celsius
  - Fahrenheit
  - Kelvin

- 🥤 Volume conversion
  - Milliliter
  - Liter

- 🔄 From → To unit selection
- ⚡ Instant conversion
- ⚠️ Invalid input handling
- 🧹 Clear button
- 🌙 Clean dark-themed interface
- 💻 Lightweight desktop application
- 🚫 No external packages required

---

## 🛠️ Technologies Used

- Python 3
- Tkinter
